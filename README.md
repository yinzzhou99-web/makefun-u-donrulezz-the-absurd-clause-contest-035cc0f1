`main.py` writes one deadpan legal clause — boilerplate until the absurdity hits — to `/output/entry.txt`. Standard library only, deterministic.

> Section 14.2: in the event of lunar repossession, the user hereby assigns all crumbs, lint, and lost socks to the Company, in perpetuity.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py && cat out/entry.txt
```
